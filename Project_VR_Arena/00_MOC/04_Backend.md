#### В нашем проекте мы используем Python для backend части. Для связи с бд мы будем использовать FastAPI. 

#### Структура проекта:
- **Backend**
	- .env - Файл который хранит строку подключения. Для безопасности используем библиотеку python-dotenv
	- databases.py - Файл к котором мы подключаемся к нашей бд и создаем сессию в которой мы будем обрабатывать запросы пользователей. Используем sqlФlchemy
	- models.py - Файл который хранит классы наших таблиц из бд.
	- schemas.py - Файл который хранит классы получения и обработку данных с сервиса. Используем библиотеку pydantic для валидации.
	- main.py - Файл в котором мы будем подключать наш бэкенд. Тут мы используем FastAPI. Для тестирования запросов буду использовать Swagger
	- auth.py - Файл в котором прописана логика хэширования и верификация паролей. Использую BCrypt
